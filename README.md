# File sorting script
## About the project
I developed this script for myself. It was so annoying to keep a lot of files in my directories that's why i created script. It helps to sort all files and separate them all in their directories.
## Features
This app has one feature it has 2 modes for your sorting i made for different situations first mode allows me to sort most common files like pictures, videos, archives and etc and second mode 
allows the same but add code sorting and exe files sorting.
And i did data validation as well.

## Tools
+ Python: 3.12.3
## Installation
How to install:

1) git clone https://github.com/Syqrix/Notes-app.git
2) In directory you will see python file. you can copy it and switch directory you want to sort
3) Write down in your console: python/python3 file-sorting.py
